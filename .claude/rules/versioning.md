# Конвенции версионирования

- **Конфиг gateway:** semver в обязательном поле `version` (`version: 1.0.0`). Пишется в каждое telemetry-событие (`configVersion`) — это инвариант ядра. Версия в имени файла (`gateway.v1.0.0.yaml`) — конвенция, не обязательна. Бамп при изменении формата или семантики конфига.
- **Схемы и контракты (structured_output, policy):** версия — суффиксом в ключе схемы (`answer_v1`) и/или в имени контракт-файла (`policy_v1.0.0.json`). Бамп при изменении схемы. Версию в содержимом файла не дублируем.
- **npm-пакет `@kir-str/llm-gateway`:** semver в `package.json`. Стадия early stage — API нестабилен; ломающие изменения возможны в minor до `1.0.0`, фиксируются в README / CHANGELOG.
- **Документы (design-спеки, roadmap, run-book):** версия или дата в имени файла (`2026-07-03-llm-gateway-design.md`; `roadmap_v1.md` → `roadmap_v2.md` при ломающей переработке). Мелкие правки — на месте в той же версии.
